RESEARCH HOVER FIGURES — how they work
======================================

When a visitor hovers over a project in the "Research" section, a figure
fades into view (bottom-right). Each project points to a file in this folder:

  Project 1  ->  figures/fig-1.svg
  Project 2  ->  figures/fig-2.svg
  ... etc. (fig-1.svg through fig-9.svg)

Right now each fig-N.svg is a BRANDED PLACEHOLDER so the effect works
immediately. Replace each with the real figure from the representative
lab paper below.

How to add the real figures
---------------------------
Easiest: send me the figure images in chat and I'll crop, rename, and wire
them in (any format).

Or do it yourself: export each figure and save it INTO this folder. The
project references an .svg file, so either save as fig-N.svg, or tell me the
format you used and I'll update the reference (e.g. to fig-N.png / fig-N.jpg).

Note: please make sure you have the right to reproduce each figure (your own
published figures are usually fine; some publishers require a credit line).
