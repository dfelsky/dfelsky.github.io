HEADSHOTS — how to add member photos
=====================================

The website looks for member photos in THIS folder. Each member's card
shows their initials until a matching image file is present here; as soon
as you add the file with the exact name below, the photo appears
automatically (no code changes needed).

Format: square-ish JPG, ~400x400 px or larger works well (.jpg).
If a file is missing, that member simply keeps their initials avatar.
